南科大 TIS 抢课助手 Windows 版
================================

使用方法
--------

1. 完整解压压缩包，不要直接在压缩包内运行。
2. 用记事本打开 courses.txt，在注释行下方按优先顺序每行填写一个 TIS 当前显示的完整教学班名称，然后保存。名称必须与 TIS 显示完全一致。
3. 双击 Snatcher.exe。
4. 按程序提示登录、检查课程匹配结果并确认提交。
5. 如果暂时不知道完整教学班名称，可以保留 courses.txt 中的注释模板；程序登录后会提供关键词搜索和编号选择，并自动写入 courses.txt。
6. 课程缓存和浏览器登录资料均保存在程序所在目录。

本版本无需安装 Python。使用浏览器登录模式时，电脑需要安装 Google Chrome。
Windows SmartScreen 首次运行时可能显示未知发布者提示；请核对下载来源后自行决定是否运行。
