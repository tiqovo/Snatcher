# 南科大 TIS 抢课助手

用于查询当前学期教学班、检查目标课程，并在用户确认后按顺序尝试选课。学号和密码只在运行时输入，密码不会显示或保存。

## Windows 打包版

没有 Python 环境的 Windows 用户可以下载 [最新 Windows 打包版](https://github.com/tiqovo/Snatcher/releases/latest/download/Snatcher-Windows-x64.zip)。使用步骤：

1. 完整解压压缩包，不要直接在压缩包内运行。
2. 用记事本打开同一目录中的 `courses.txt`，按优先顺序每行填写一个 TIS 当前显示的完整教学班名称并保存。
3. 双击 `Snatcher.exe`，按程序提示登录、检查匹配结果并确认执行。

使用浏览器登录模式时仍需安装 Google Chrome。Windows SmartScreen 首次运行时可能显示未知发布者提示，请核对下载来源后自行决定是否运行。

## 从源码安装

要求 Python 3.10+ 和 Google Chrome。首次使用时在 PowerShell 中运行：

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -e .
```

## 最简单的使用方式

首次运行前，先用文本编辑器打开项目目录中的 `courses.txt`，按优先顺序每行填写一个 TIS 当前显示的完整教学班名称并保存。以 `#` 开头的说明行会被忽略。

配置完成后，可以直接双击 `start-snatcher.cmd`。它会自动进入项目目录并优先使用 `.venv` 中的 Python，程序结束后窗口也会保留，方便查看结果。

也可以在项目目录的 PowerShell 中只运行一条命令：

```powershell
.\start-snatcher.cmd
```

或者直接使用 Python：

```powershell
python -m snatcher
```

程序会逐步提示用户完成：

1. 输入学号。
2. 输入统一认证密码。密码不回显，也不会保存。
3. 读取当前学期并检查课程缓存。如果存在属于当前学期的缓存，程序会显示课程数量，并询问是否从服务器重新获取和更新；直接回车默认保留缓存。如果没有缓存、缓存损坏或学期不符，则自动读取服务器课程列表。随后确认已经配置的课程；如果还没有实际课程，可直接输入关键词搜索并用编号选择，选择结果会写入 `courses.txt`。
4. 输入开始时间，直接回车使用默认 `13:00:00`；输入 `now` 可立即开始。
5. 输入抢课间隔，直接回车使用自动模式。
6. 查看匹配结果并确认是否执行。

交互模式会显示登录、读取学期、缓存命中或服务器读取、匹配课程、等待开始、每次提交结果及间隔调整过程，不需要用户研究命令行参数。

默认最多运行三分钟。如果启动时当天 13:00 已经过去，程序会明确显示正在等待次日 13:00；需要立即测试时，在开始时间提示中输入 `now`。

## 自动抢课间隔

直接回车选择自动模式后，程序会：

- 从 `1.5` 秒间隔开始。
- 每连续四次请求未触发限流，将间隔缩短 `0.25` 秒。
- 最低尝试到 `0.5` 秒。
- 一旦 TIS 返回频率限制，立即加倍间隔，且不再回到刚刚触发限制的间隔。
- 后续请求稳定后，再逐步缩短到新的安全下限。

选课提交接口的限制只能从真实提交响应判断。程序不会为了测速额外发送可能改变选课状态的请求；自动调整只利用正常抢课过程中已经产生的响应。因此，它能够逐步寻找当前会话下较快的有效间隔，但无法在开始前保证一个固定的全局最小值。

如果用户在提示中直接填写数字，例如 `2.5`，程序会将其作为固定基础间隔；发生限流时仍会临时降低请求速度。

## 课程选择

`courses.txt` 每行保存一个 TIS 当前显示的完整教学班名称。请将模板中的说明保留为 `#` 注释，并在其下方填写实际课程；多门课程表示这些课程都需要尝试，行的顺序决定首次尝试顺序。例如：

```text
# 每行填写一个 TIS 当前显示的完整教学班名称。
大学物理（下）-01班-双语
普通化学-02班-中文
```

名称必须与 TIS 显示完全一致。暂时不知道完整名称时，可以保留纯注释模板并运行程序，登录后使用关键词搜索和编号选择，选择结果会自动写入 `courses.txt`。缓存有效时可以选择直接使用或重新获取；缓存不可用时会自动读取服务器课程列表：

```text
请输入课程关键词：物理 双语
请输入要选择的编号：1,3
```

空格分隔的关键词必须同时出现在课程名称中。搜索结果超过 30 门时，程序会提示增加关键词缩小范围。

某门课程暂时已满时，程序会保留它并轮询下一门，不会让第一门课程长期阻塞其他目标。成功、已选、冲突或重复等终态响应会停止重试对应课程。

## 安全行为

- 实际提交前会显示精确匹配结果，并要求用户输入 `y` 确认。
- 终端密码模式不保存学号、密码或登录资料。
- 程序不会绕过验证码、多因素认证或服务器频率限制。
- TLS 证书校验保持开启，所有网络请求均有超时。
- `.browser-profile/`、课程缓存、日志、虚拟环境和测试缓存均已加入 `.gitignore`。
- 请遵守学校选课规定；课程容量、选课规则、服务器负载和网络延迟均不受程序控制，程序不能保证选课成功。

## 高级用法

通常不需要下面的参数。自动化或排查问题时仍可使用：

```powershell
# 只检查课程，不提交
python -m snatcher --prepare --refresh

# 只读搜索课程
python -m snatcher --search "物理 双语" --refresh

# 浏览器登录，用于验证码或额外认证
python -m snatcher --prepare --refresh --login-mode browser

# 跳过交互确认，按默认 13:00 和自动间隔执行
python -m snatcher --confirm-submit

# 立即开始并使用固定两秒间隔
python -m snatcher --confirm-submit --start-now --interval 2
```

使用高级参数执行实际提交时，必须显式添加 `--confirm-submit`。`--prepare` 和 `--search` 永远不会发送选课请求。
